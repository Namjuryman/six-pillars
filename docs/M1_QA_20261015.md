本人账户的邮箱送达、真实登录链接、SDK 回调及后台恢复已实测。后续本机验收工具一度因加密模块缺失中断，修复并做系统加密接口自测后继续；未把失败的完整运行记为通过。

## 遗留与限制

1. 尚未在真实手机和另一台电脑上由本人独立登录抽验；当前是三种真实浏览器视口及独立上下文。
2. 默认 SMTP 仅支持组织成员等限制，发送额度有限；未配置生产 SMTP。
3. 最终安全 Advisor 有 1 项 WARN：泄露密码保护未开启。当前 Free 计划不能启用该功能，官方说明为 Pro 及以上可用：[配置与修复说明](https://supabase.com/docs/guides/auth/password-security#password-strength-and-leaked-password-protection)。本次未付费升级，也没有声称警告已修复。无 RLS 缺失或性能 Advisor 告警。
4. 排序使用多条 owner 行更新，未实现事务式批量重排；网络中途失败时会重新读取真实顺序并显示错误，可用自定义顺序修正。后续若需要严格原子重排，再设计受 RLS 保护的 RPC。
5. 正式生产 Supabase 配置、生产回调和上线验证不在本轮；没有将开发项目接到正式 Pages。

等待代码审阅、上述独立设备抽验及上线配置取舍后，再批准合并和 M1 正式验收。
